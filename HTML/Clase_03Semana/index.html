Arquitectura Semántica en HTML5

Concepto de Maquetación Semántica

La maquetación semántica es la práctica de utilizar etiquetas HTML que describen su contenido y función en el documento, permitiendo que navegadores, motores de búsqueda (SEO) y tecnologías de asistencia (lectores de pantalla) comprendan la jerarquía y el propósito de cada sección de la página.

Definición de Componentes Estructurales

Etiqueta Header Representa la cabecera de una página o de una sección específica. Se utiliza para agrupar elementos introductorios como el logotipo del sitio, el título principal (h1), formularios de búsqueda o banners destacados. Etiqueta Nav Define un bloque que contiene enlaces de navegación. Su propósito es agrupar los menús principales que permiten al usuario moverse a través del sitio web o saltar a secciones dentro de la misma página. Etiqueta Main Es el contenedor del contenido central y único de la página. No debe incluir información que se repita en otros documentos (como barras laterales o menús). Por estándar, solo debe existir un elemento main visible por cada archivo HTML. Etiqueta Section Representa una agrupación temática de contenido. Se utiliza para dividir la página en capítulos, pestañas o bloques lógicos. Cada sección debe tener idealmente un encabezado (h2-h6) que identifique su tema. Etiqueta Article Define una composición autónoma e independiente. Un artículo debe tener sentido por sí mismo y ser distribuible de forma aislada, como una entrada de blog, una noticia, un comentario de usuario o un widget interactivo. Etiqueta Aside Se utiliza para contenido relacionado de forma tangencial o indirecta con el contenido principal. Es el lugar adecuado para barras laterales, glosarios, publicidad, biografías cortas del autor o grupos de enlaces relacionados. Etiqueta Footer Representa el pie de página o de una sección. Generalmente contiene información sobre el autor, datos de copyright, enlaces a documentos legales, redes sociales y fechas de publicación. Etiqueta Div Es un contenedor genérico sin valor semántico. Se debe utilizar únicamente como último recurso cuando se requiere agrupar elementos con el solo propósito de aplicar diseño o estilos mediante CSS, sin que dicha agrupación tenga un significado lógico.

Principios de Implementación

Significado sobre Diseño: No elijas una etiqueta por cómo se ve en el navegador, sino por lo que representa el contenido que lleva dentro. Accesibilidad (A11y): El uso correcto de estas etiquetas permite que las personas con discapacidad visual naveguen rápidamente entre regiones de la página. Posicionamiento SEO: Los algoritmos de búsqueda priorizan el contenido indexado dentro de etiquetas semánticas, otorgando mayor relevancia a lo que se encuentra en main y article.

Concepto de Enlaces (Hipervínculos)

Los enlaces son el componente fundamental de la Web (el "HyperText" de HTML). Su función es permitir la navegación entre diferentes recursos digitales. Sin enlaces, la web sería solo una colección de documentos aislados.

1. La Etiqueta de Anclaje (a)

Para crear un enlace se utiliza la etiqueta (a) (del inglés anchor). Esta etiqueta requiere atributos específicos para funcionar: Atributo href (Hypertext Reference): Es obligatorio. Indica la dirección (URL) o el archivo al que el usuario será dirigido al hacer clic. Atributo target: Define dónde se abrirá el enlace. El valor _blank es el más usado para abrir el contenido en una pestaña nueva sin cerrar la actual. Texto de Anclaje: Es el texto visible y clicable que queda entre (a) y (/a).

2. Tipos de Enlaces según su destino

En tu enciclopedia es importante distinguir estos tres tipos, ya que se usan constantemente en la maquetación: Enlaces Externos: Apuntan a un sitio web diferente al tuyo. Requieren la URL completa (ejemplo: https://www.google.com). Enlaces Internos (Relativos): Conectan con otros archivos dentro de tu propio proyecto. Por ejemplo, para ir de tu página principal a tu página de contacto (ejemplo: contacto.html). Enlaces de Ancla (Internos a la página): Se usan para saltar a una sección específica de la misma página. Para esto, se usa el símbolo # seguido del id de la etiqueta de destino ejemplo: (a href="#maquetacion">Ir a Maquetación/a).

3. Relación con la Maquetación

En los Enlaces que aparecen arriba de Maquetación porque, normalmente, lo primero que diseñamos es cómo se conectará nuestro sitio. Estos enlaces casi siempre se agrupan dentro de la etiqueta semántica (nav) (Navegación) para formar los menús que vemos en la parte superior de las páginas.
