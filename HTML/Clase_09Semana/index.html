HTML Forms

En esta sesión aprendimos que los Formularios HTML5 son la base de la interacción usuario-servidor. Usamos etiquetas como <form>, <input> y <label> para crear interfaces de captura. Además, exploramos cómo la Subida a la Nube permite que nuestros proyectos sean accesibles globalmente a través de servidores remotos y se integran con github como vercel o digital ocean.

Un formulario HTML se utiliza para recoger la entrada del usuario. La entrada del usuario se envía normalmente a un servidor para su procesamiento.

<form>
  . . . elementos del formulario . . .
</form>

El Elemento <input>

El elemento <input> es el elemento de formulario más importante. Puede mostrarse de varias formas, dependiendo del atributo type.

Tipo Descripción
<input type="text"> Muestra un campo de entrada de texto de una sola línea.
<input type="radio"> Muestra un botón de opción (para seleccionar una de muchas opciones).
<input type="checkbox"> Muestra una casilla de verificación (para seleccionar cero o más opciones).
<input type="submit"> Muestra un botón de envío (para enviar el formulario).
<input type="button"> Muestra un botón en el que se puede hacer clic.

Campos de Texto

Define un campo de entrada de una sola línea para la entrada de texto:

<label for="fname">First name:</label><br>
<input type="text" id="fname" name="fname">
Nota: El formulario en sí no es visible. Además, el ancho predeterminado de un campo de entrada es de 20 caracteres.

La Etiqueta <label>

La etiqueta <label> define una etiqueta para muchos elementos de formulario.

Es útil para usuarios de lectores de pantalla y para usuarios que tienen dificultades para hacer clic en regiones pequeñas (como botones de radio o casillas de verificación).

Botones de Radio

Permiten al usuario seleccionar UNA de un número limitado de opciones:

<input type="radio" id="html" name="fav_lang" value="HTML">
<label for="html">HTML</label>

El Botón de Envío (Submit)

El <input type="submit"> define un botón para enviar los datos del formulario a un manejador de formularios (form-handler).

<input type="submit" value="Submit">

Atributos de Formulario Necesarios

Atributo Descripción
target Especifica dónde mostrar la respuesta que se recibe después de enviar el formulario (_blank, _self, _parent, _top).
action Define la acción que se realizará cuando se envíe el formulario.
method Especifica el método HTTP (GET o POST) que se usará al enviar los datos.
¡Importante! Si se omite el atributo name en un campo de entrada, los datos de ese campo no se enviarán en absoluto.
