Clase 7: Maquetación (Flexbox & Grid) y Navegación

1. ¿Para qué usamos Flexbox?

Implementamos Flexbox como un modelo de diseño unidimensional. Su función principal es permitir que los elementos dentro de un contenedor (como nuestro menú) se alineen y distribuyan el espacio de forma flexible. Lo usamos para que los botones de navegación se centren automáticamente y no se amontonen, facilitando una interfaz limpia.

2. ¿Para qué usamos CSS Grid?

A diferencia de Flexbox, utilizamos CSS Grid para la maquetación bidimensional. Esto nos sirve para organizar estructuras más complejas como el Footer, donde necesitamos controlar filas y columnas simultáneamente. Con Grid, definimos rejillas precisas que mantienen el orden de las tarjetas de información sin importar el tamaño de la pantalla.

3. Navegación Responsive (JavaScript)

Para que el sitio sea "Mobile First", usamos la lógica de W3Schools. Declaramos un contenedor <nav class="topnav" id="myTopnav">. Mediante JavaScript, creamos un activador para el icono de barras que alterna la clase a "responsive", permitiendo que el menú pase de ser horizontal (Flexbox) a una lista vertical funcional en celulares.

Resumen Técnico

1. Flexbox: Alineación de menús e iconos en un solo eje.
2. Grid: Creación de la estructura general y rejillas del pie de página.
3. DOM: Manipulación de clases con JS para la interactividad.

Análisis Técnico de Maquetación

Uso de Flexbox: Aplicamos display: flex en el menú secundario (.topnav-ejercicio) para lograr una alineación horizontal fluida de los enlaces. Esto permite que el menú sea "Flexible", ajustando el espacio entre botones automáticamente.

Uso de CSS Grid: La estructura del pie de página utiliza display: grid. A diferencia de Flexbox, Grid nos permite crear una rejilla bidimensional para organizar la "Información de elaboración", el "Estado del Proyecto" y los "Links Sociales" en columnas perfectas que se mantienen alineadas tanto en ancho como en alto.
