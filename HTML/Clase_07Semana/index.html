Clase 7: Maquetación y Navegación Desplegable

Arquitectura de Navegación Responsive En esta sesión implementamos un Menú de Navegación Adaptativo (Mobile First), utilizando la lógica de W3Schools para transformar una lista de enlaces en un Menú Hamburguesa. 1. Estructura Semántica (HTML5) Para que el navegador entienda nuestra jerarquía, declaramos un contenedor principal con identidad única: Contenedor: Un div> o nav> con class="topnav" e id="myTopnav". Elementos: Enlaces directos a> para las secciones. Trigger (Activador): Un enlace especial con el atributo javascript:void(0); para evitar que la página recargue al hacer clic. 2. Implementación del Ícono (FontAwesome) Insertamos el ícono de barras (fa fa-bars) dentro del activador. Este será el botón que el usuario verá en dispositivos móviles. 3. Lógica de Control (JavaScript) Para cambiar el estado del menú (abierto/cerrado), ejecutamos una función que manipula el DOM: JavaScript function myFunction() { var x = document.getElementById("myTopnav"); // Lógica: Si la clase es "topnav", cámbiala a "topnav responsive" if (x.className === "topnav") { x.className += " responsive"; } else { x.className = "topnav"; } } 📈 Resumen del Flujo de Trabajo: Definir el contenedor e ID. Declarar los enlaces (anchor tags). Inyectar el ícono con la clase icon. Ejecutar el Script para alternar la clase según el ancho de pantalla.
