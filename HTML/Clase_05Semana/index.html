Fundamentos de CSS

1. Conceptos Generales: CSS

CSS es un lenguaje de diseño gráfico que permite aplicar estilos a los documentos HTML. Su función es separar el contenido (HTML) de la presentación (colores, fuentes, espacios). La palabra "Cascading" (Cascada) significa que si hay varias reglas aplicadas a un mismo elemento, el navegador sigue un orden de prioridad para decidir cuál usar.

2. Versiones de CSS

CSS1 y CSS2: Sentaron las bases de fuentes, colores y bordes. CSS3: La versión moderna y actual. Introdujo bordes redondeados, sombras, degradados, transiciones, animaciones y diseños flexibles (Flexbox y Grid). Actualmente no se habla de un "CSS4" oficial, sino de módulos que se actualizan constantemente.

3. Sintaxis de CSS

Una regla de CSS se compone de tres partes: Selector: Indica a qué elemento se le aplica el estilo (ej: p). Propiedad: Qué característica queremos cambiar (ej: color). Valor: El ajuste específico (ej: blue). Estructura: selector { propiedad: valor; }

4. Hoja de Estilos: Identificadores y Selectores

Para que CSS sepa exactamente a qué elemento "apuntar", usamos tres métodos principales: Selector de Etiqueta: Aplica el estilo a todas las etiquetas de ese tipo (ej: todos los h1). Clase (.clase): Se usa para aplicar un mismo estilo a varios elementos diferentes. En el HTML se escribe class="nombre" y en CSS se identifica con un punto (ej: .boton-rojo). ID (#id): Se usa para identificar un único elemento en toda la página. Es irrepetible. En el HTML se escribe id="nombre" y en CSS se identifica con un numeral (ej: #logo).

5. Estilos para Fondos, Texto y Párrafos

Estilos para Fondos (Background)

Permiten decorar el área detrás del contenido. background-color: Define el color sólido de fondo. background-image: Coloca una imagen de fondo. background-size: Ajusta el tamaño de la imagen (ej: cover para que llene todo).

Estilos para Texto (Font)

Controlan la apariencia de las palabras individualmente. font-family: Define el tipo de letra (Arial, Roboto, etc.). font-size: El tamaño de la letra (px, em, rem). font-weight: El grosor de la letra (bold, normal). color: El color del texto.

Estilos para Párrafos (Text)

Controlan la alineación y el comportamiento del bloque de texto. text-align: Alineación (left, right, center, justify). line-height: El espacio entre líneas (interlineado). text-decoration: Para quitar o poner subrayados (none, underline). text-indent: Sangría al inicio del párrafo.
