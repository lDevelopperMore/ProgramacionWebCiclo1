Estructura y Estilos de Listas, Tablas y Marcos

1. Estilos para Listas (ul, ol, li) Controlan el marcador y su posición. list-style-type: Cambia el icono (punto, círculo, cuadrado). Valores: disc (por defecto), circle, square, none. list-style-position: Dónde se coloca el punto. Valores: inside (dentro del bloque de texto) o outside (fuera, alineado a la izquierda). list-style-image: Permite usar una imagen pequeña como viñeta: url('imagen.png'). 2. Estilos para Tablas (table, th, td) Lo más importante aquí es el manejo de los bordes para que no se vean dobles. border-collapse: La propiedad reina de las tablas. collapse: Une los bordes de celdas adyacentes en uno solo. separate: Mantiene los bordes separados (estilo antiguo). border-spacing: Si usas separate, define cuántos píxeles de distancia hay entre celdas. empty-cells: Define si se muestran o no los bordes en celdas que no tienen contenido (show o hide). 3. Estilos para Marcos (Bordes) El "marco" es la propiedad border, que es un atajo (shorthand) de tres valores. Sintaxis corta: border: [grosor] [estilo] [color]; Ejemplo: border: 2px solid black; Estilos de línea (border-style): solid: Línea continua. dashed: Línea de guiones. dotted: Línea de puntos. double: Línea doble. groove / ridge: Efectos 3D de relieve. Redondeo: border-radius: 10px; (Cuanto mayor el número, más circular es la esquina).
